METODA SEGMENTELOR

Problema Activă #1

Suma a două numere este 48, iar unul dintre numere este de 3 ori mai mare decât celălalt. Află cele două numere folosind metoda grafică.

Visual Hint / Reprezentare Grafică:
Numărul mic (1 segment):
x
Numărul mare (3 segmente):
x
x
x
Total = 4 segmente egale = 48

📖 Explicație Metodică Pas cu Pas:

  1. Reprezentăm numărul mic printr-un segment de lungime 1.
  2. Numărul mare este de 3 ori mai mare, deci are 3 segmente egale.
  3. Suma totală este formată din 1 + 3 = 4 segmente egale.
  4. Aflăm valoarea unui segment: 48 ÷ 4 = 12 (numărul mic).
  5. Aflăm numărul mare: 12 × 3 = 36.
  6. Verificare: 12 + 36 = 48. Corect!
